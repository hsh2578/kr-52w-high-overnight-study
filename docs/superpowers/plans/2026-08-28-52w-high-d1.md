# 52주 신고가 돌파 D+1 예측 연구 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 52주 신고가를 돌파한 종목의 익일 시가청산 수익률을 예측하고, 피처군(기존 14 / D+1 특화 10 / qlib Alpha158 계열 20 / 재료 5)의 기여도를 5단 ablation으로 측정해 학회 발표용 리포트와 그림을 산출한다.

**Architecture:** 순수 함수 중심의 파이프라인. `sources`(로컬 캐시 읽기) → `events`(이벤트+라벨) → `features_f1~f5`(피처군별 독립 모듈) → `dataset`(조립 후 parquet) → `validate`(walk-forward·embargo·가중·보정·통계검정) → `models`(M0~M5) → `report`(figure+리포트). 각 피처 모듈은 `(df, i, ctx) -> dict` 시그니처를 공유해 서로 독립적으로 테스트된다. 네트워크는 `sources`와 `predict.py`에만 존재한다.

**Tech Stack:** Python 3.13, pandas 2.3, numpy, LightGBM 4.6, scikit-learn 1.8, scipy 1.17, matplotlib 3.10, FinanceDataReader 0.9.101, pytest

**Spec:** `docs/superpowers/specs/2026-08-28-52w-high-d1-design.md`

## Global Constraints

- 왕복거래비용은 **0.0021** 고정 (상수 `COST`). 스펙 §6.
- 이벤트 조건: `Close[i] > max(Close[i-252:i])` **AND** `Volume[i] >= 1.5 * nanmean(Volume[i-50:i])` **AND** `Close[i]*Volume[i] >= 1e10` **AND** `i >= 260` **AND** `i+1 < len(df)` **AND** 최근 5봉과 익일 봉에 거래정지가 없을 것. 스펙 §3.1.
- **거래정지 봉 처리 (필수)**: 원본 데이터는 거래정지일을 `Open=0, Volume=0, Close=직전값`으로
  채운다(예: 카카오 035720 액면분할 2021-04-12~14). 전체 봉의 `Open<=0` 0.99%,
  `Volume<=0` 1.25%. 방치하면 `y_raw`가 −100%가 되고 거래량 평균이 왜곡된다.
  → `sources.load_ohlcv()` 에서 `halted` 컬럼을 만들고 해당 봉의 `Open/Volume`을 `NaN`으로
  바꾼다. 롤링 통계는 NaN을 건너뛴다. 제외된 이벤트 수를 리포트에 기록한다.

```python
    return pd.DataFrame(
        {"Open": o, "High": h, "Low": l, "Close": c, "Volume": v},

def test_build_market_index_등가중수익률과_갭을_계산한다():
```

`surge_d1/sources.py`:

```python
# -*- coding: utf-8 -*-
"""데이터 로더. 로컬 캐시만 읽고 네트워크를 쓰지 않는다.

pickle 사용 주의: 읽는 pkl은 1st-party 로컬 캐시다(HollyKR 프로젝트가 자기
머신에서 쓴 것, 또는 scripts/refresh_cache.py 가 쓴 것). 외부 파일을
역직렬화하지 않는다.
"""
from __future__ import annotations

import pickle
import re

import numpy as np
import pandas as pd

from surge_d1 import config

OHLCV_COLS = ["Open", "High", "Low", "Close", "Volume"]


def mark_halted(df: pd.DataFrame) -> pd.DataFrame:
    """거래정지 봉을 표시하고 Open/Volume을 NaN으로 바꾼다.

    원본(FDR/네이버)은 거래정지일을 Open=0·Volume=0·Close=직전값으로 채운다.
    예: 카카오(035720) 2021-04-15 액면분할 처리로 04-12~14 정지.
    이 값을 그대로 두면 라벨이 −100%가 되고 거래량 평균이 왜곡되므로 NaN 처리한다.
    Close는 직전값이 그대로 유효한 참조가이므로 건드리지 않는다.
    """
    out = df.copy()
    halted = (out["Open"].fillna(0) <= 0) | (out["Volume"].fillna(0) <= 0)
    out["halted"] = halted.to_numpy()
    out.loc[halted, "Open"] = np.nan
    out.loc[halted, "Volume"] = np.nan
    return out


def load_ohlcv() -> dict[str, pd.DataFrame]:
    """갱신본이 있으면 그것을, 없으면 HollyKR 원본을 읽는다.

    원본은 key가 "{code}_{days}" 형태라 code별 최장 시계열만 남긴다.
    반환 전에 mark_halted를 적용한다.
    """
    if config.CACHE_PATH.exists():
        with open(config.CACHE_PATH, "rb") as f:
            cache = pickle.load(f)
        if cache and not re.match(r"\d+_\d+$", next(iter(cache))):
            return {k: mark_halted(v[OHLCV_COLS])
                    for k, v in cache.items() if v is not None}
    else:
        path = config.HOLLYKR_CACHE / "ohlcv" / "ohlcv_cache.pkl"
        with open(path, "rb") as f:
            cache = pickle.load(f)

    best: dict[str, pd.DataFrame] = {}
    for key, df in cache.items():
        m = re.match(r"(\d+)_(\d+)$", str(key))
        code = m.group(1) if m else str(key)
        if df is None or len(df) == 0:
            continue
        if code not in best or len(df) > len(best[code]):
            best[code] = df
    return {c: mark_halted(d[OHLCV_COLS]) for c, d in best.items()}


def load_catalyst() -> pd.DataFrame:
    """재료 CSV → 정규화된 DataFrame.

    반환 컬럼: date, code, ctype, reason, day_chg, d1
    """
    raw = pd.read_csv(config.CATALYST_CSV, encoding="utf-8")
    raw.columns = ["date", "name", "code", "chg_s", "day_chg",
                   "ctype", "reason", "d1", "d2", "d3", "cum3"]
    out = pd.DataFrame({
        "date": pd.to_datetime(raw["date"]),
        "code": raw["code"].astype(str).str.zfill(6),
        "ctype": raw["ctype"].fillna("").astype(str).str.strip(),
        "reason": raw["reason"].fillna("").astype(str).str.strip(),
        "day_chg": pd.to_numeric(raw["day_chg"], errors="coerce"),
        "d1": pd.to_numeric(raw["d1"], errors="coerce"),
    })
    return out.reset_index(drop=True)


def build_market_index(ohlcv: dict[str, pd.DataFrame]) -> pd.DataFrame:
    """전 종목 등가중 시장 지수. FDR의 KS11 호출이 불안정해 대용으로 쓴다.

    반환: index=Date, columns=[ret, gap, n]
      ret = 종목별 (Close/Close[-1] - 1) 의 그날 평균
      gap = 종목별 (Open/Close[-1] - 1) 의 그날 평균
      n   = 그날 계산에 쓰인 종목 수
    """
    rets, gaps = [], []
    for df in ohlcv.values():
        c = df["Close"].astype(float)
        o = df["Open"].astype(float)
        prev = c.shift(1)
        rets.append((c / prev - 1.0).rename(None))
        gaps.append((o / prev - 1.0).rename(None))
    r = pd.concat(rets, axis=1)
    g = pd.concat(gaps, axis=1)
    out = pd.DataFrame({
        "ret": r.mean(axis=1, skipna=True),
        "gap": g.mean(axis=1, skipna=True),
        "n": r.count(axis=1).astype(int),
    }).sort_index()
    out.loc[out["n"] == 0, ["ret", "gap"]] = np.nan
    return out
```

```python
# -*- coding: utf-8 -*-
"""52주 신고가 돌파 이벤트 스크린과 D+1 라벨. 스펙 §3.1, §6.

pickle 사용 주의: 읽는 krx_master_*.pkl 은 HollyKR 프로젝트가 자기 머신에서 쓴
1st-party 로컬 캐시다. 외부에서 받은 파일을 역직렬화하지 않는다.
"""
from __future__ import annotations

import pickle

import numpy as np
import pandas as pd

from surge_d1 import config


def is_breakout(df: pd.DataFrame, i: int) -> bool:
    """봉 i가 52주 신고가 돌파 이벤트인가.

    조건 (스펙 §3.1): 신고가 · 거래량 1.5배 · 거래대금 100억 · i>=260 · 익일 존재
    · 최근 HALT_LOOKBACK봉과 익일 봉에 거래정지 없음
    """
    if i < config.MIN_BAR_INDEX or i + 1 >= len(df):
        return False

    # 거래정지 배제: 정지 구간은 Open/Volume이 NaN이라 지표가 왜곡된다
    if "halted" in df.columns:
        lo = max(0, i - config.HALT_LOOKBACK + 1)
        if bool(df["halted"].iloc[lo:i + 2].any()):
            return False

    c = float(df["Close"].iloc[i])
    v = float(df["Volume"].iloc[i])
    if not np.isfinite(c) or not np.isfinite(v) or c <= 0:
        return False

    prior_high = float(df["Close"].iloc[i - config.HIGH_52W_PERIOD:i].max())
    if not (c > prior_high):
        return False

    # NaN(정지봉)을 건너뛴 평균
    vol_avg = float(df["Volume"].iloc[i - 50:i].mean())
    if not (np.isfinite(vol_avg) and vol_avg > 0
            and v >= config.VOLUME_SURGE_MULT * vol_avg):
        return False

    return bool(c * v >= config.MIN_TRADING_VALUE)


def labels(df: pd.DataFrame, i: int, cost: float = config.COST) -> dict:
    """봉 i 종가 매수 기준 라벨 3종. 스펙 §6.

    y_raw  = (Open[i+1]-Close[i])/Close[i] - cost   (익일 시가청산)
    y_hold = (Close[i+1]-Close[i])/Close[i] - cost  (익일 종가청산)
    y_cls  = 1 if y_raw > 0 else 0
    """
    c = float(df["Close"].iloc[i])
    o1 = float(df["Open"].iloc[i + 1])
    c1 = float(df["Close"].iloc[i + 1])
    y_raw = (o1 - c) / c - cost if (c > 0 and o1 > 0) else np.nan
    y_hold = (c1 - c) / c - cost if (c > 0 and c1 > 0) else np.nan

    # 20일 보유(보조 비교용). 미래 봉이 없으면 NaN — **이벤트 자격 조건으로 쓰지 않는다.**
    # 20봉 미래를 요구하면 최근 한 달 이벤트를 통째로 잃는다.
    y_hold20 = np.nan
    if c > 0 and i + 20 < len(df):
        c20 = float(df["Close"].iloc[i + 20])
        if c20 > 0 and np.isfinite(c20):
            y_hold20 = (c20 - c) / c - cost

    return {
        "y_raw": y_raw,
        "y_hold": y_hold,
        "y_hold20": y_hold20,
        # y_cls = 비용 차감 후 이익 확률 (학습 타깃)
        "y_cls": int(y_raw > 0) if np.isfinite(y_raw) else 0,
        # y_up = 비용 전 순수 주가 상승 여부. 학습하지 않고 리포트 집계에만 쓴다
        # ("상승확률 X% / 비용 넘길 확률 Y%" 대비를 위해).
        "y_up": int(o1 > c) if (c > 0 and o1 > 0) else 0,
    }


def load_excluded_codes() -> set[str]:
    """제외할 코드(우선주 등 비보통주) 집합.

    HollyKR 마스터의 `is_common` 만 쓴다. `is_etf` 는 신뢰할 수 없다 —
    삼성전자(005930)가 True 로 잘못 표시돼 있음을 실측 확인했다.
    마스터에 없는 코드(신규상장·상장폐지)는 제외하지 않는다: 상장폐지 종목을 남기는 것이
    생존편향을 줄인다.
    """
    masters = sorted(config.HOLLYKR_CACHE.glob("krx_master_*.pkl"))
    if not masters:
        return set()
    try:
        with open(masters[-1], "rb") as f:
            m = pickle.load(f)
    except Exception:
        return set()
    codes = m["종목코드"].astype(str).str.zfill(6)
    return set(codes[~m["is_common"].astype(bool)])


def collect_events(ohlcv: dict[str, pd.DataFrame],
                   exclude: set[str] | None = None) -> pd.DataFrame:
    """전 종목 순회하며 이벤트와 라벨을 모은다.

    exclude 에 든 코드는 건너뛴다(우선주 등). None 이면 필터를 걸지 않는다.
    """
    rows = []
    for code, df in ohlcv.items():
        if exclude and code in exclude:
            continue
        n = len(df)
        if n < config.MIN_BAR_INDEX + 2:
            continue
        c = df["Close"].to_numpy(dtype=float)
        v = df["Volume"].to_numpy(dtype=float)
        tval = c * v
        for i in range(config.MIN_BAR_INDEX, n - 1):
            if tval[i] < config.MIN_TRADING_VALUE:
                continue
            if not is_breakout(df, i):
                continue
            lab = labels(df, i)
            if not np.isfinite(lab["y_raw"]):
                continue
            rows.append({"code": code, "date": df.index[i], "i": i,
                         "close": c[i], **lab})
    out = pd.DataFrame(rows)
    if len(out):
        out = out.sort_values(["date", "code"]).reset_index(drop=True)
    return out


def add_market_adjusted(events: pd.DataFrame) -> pd.DataFrame:
    """같은 날 이벤트들의 y_raw 중앙값을 빼 시장조정 라벨을 만든다. 스펙 §6."""
    out = events.copy()
    med = out.groupby("date")["y_raw"].transform("median")
    out["y_mkt"] = out["y_raw"] - med
    return out
```

```python
"""F1 — 기존 프로젝트(stock-screener-kr)의 기술 피처 14개. 스펙 §5.1.

원본: stock-screener-kr/ml/src/collect_training_data.py:calculate_features()
계산식을 그대로 옮기되 기준 시점만 이벤트 봉 i로 통일한다. 재현이 목적이므로
"개선"하지 않는다.

from __future__ import annotations

import numpy as np
import pandas as pd

from surge_d1 import config

F1_NAMES = [
    "breakout_pct", "volume_surge", "close_strength",
    "base_length", "volatility_contraction", "volume_dry_up",
    "ma200_slope", "pct_above_52w_low",
    "rs_vs_market", "market_return",
    "ma20_deviation", "liquidity",
    "days_since_ath", "atr_ratio",
]


def calculate_atr(df: pd.DataFrame, period: int = 14) -> pd.Series:
    """Wilder ATR."""
    h, l, c = df["High"], df["Low"], df["Close"]
    pc = c.shift(1)
    tr = pd.concat([h - l, (h - pc).abs(), (l - pc).abs()], axis=1).max(axis=1)
    return tr.rolling(period).mean()


def _market_return_20d(market: pd.DataFrame, date, i_fallback: int) -> float:
    """시장 20일 누적 수익률(%). market은 index=Date, 컬럼 ret(일간 수익률)."""
    if market is None or date not in market.index:
        return 0.0
    loc = market.index.get_loc(date)
    if isinstance(loc, slice) or loc < 20:
        return 0.0
    window = market["ret"].iloc[loc - 19:loc + 1].fillna(0.0)
    return float((np.prod(1.0 + window.to_numpy()) - 1.0) * 100)


def compute_f1(df: pd.DataFrame, i: int, market: pd.DataFrame) -> dict:
    """봉 i의 F1 피처 14개."""
    close, high, low, vol = df["Close"], df["High"], df["Low"], df["Volume"]
    price = float(close.iloc[i])
    P = config.HIGH_52W_PERIOD

    prior_high = float(close.iloc[max(0, i - P):i].max())
    breakout_pct = (price - prior_high) / prior_high * 100 if prior_high > 0 else 0.0

    vol50 = float(vol.iloc[max(0, i - 50):i].mean())
    volume_surge = float(vol.iloc[i]) / vol50 if vol50 > 0 else 0.0

    rng = float(high.iloc[i] - low.iloc[i])
    close_strength = (price - float(low.iloc[i])) / rng if rng > 0 else 0.5

    # 직전 52주 고가가 나온 위치 이후 경과일
    seg = close.iloc[max(0, i - P):i]
    base_length = int(i - (seg.index.get_loc(seg.idxmax()) + max(0, i - P))) if len(seg) else 0

    r5 = (float(high.iloc[i - 4:i + 1].max()) - float(low.iloc[i - 4:i + 1].min())) / price
    r20 = (float(high.iloc[i - 19:i + 1].max()) - float(low.iloc[i - 19:i + 1].min())) / price
    volatility_contraction = r5 / r20 if r20 > 0 else 1.0

    vol10 = float(vol.iloc[i - 9:i + 1].mean())
    volume_dry_up = vol10 / vol50 if vol50 > 0 else 1.0

    ma200_now = float(close.iloc[i - 199:i + 1].mean())
    ma200_prev = float(close.iloc[i - 219:i - 19].mean())
    ma200_slope = (ma200_now - ma200_prev) / ma200_prev if ma200_prev > 0 else 0.0

    low_52w = float(close.iloc[max(0, i - P):i + 1].min())
    pct_above_52w_low = (price - low_52w) / low_52w * 100 if low_52w > 0 else 0.0

    stock_ret_20d = (price / float(close.iloc[i - 20]) - 1) * 100
    market_return = _market_return_20d(market, df.index[i], i)
    rs_vs_market = stock_ret_20d - market_return

    ma20 = float(close.iloc[i - 19:i + 1].mean())
    ma20_deviation = (price / ma20 - 1) if ma20 > 0 else 0.0

    liquidity = float((close * vol).iloc[i - 4:i + 1].mean())

    ath_seg = close.iloc[:i]
    days_since_ath = int(i - ath_seg.index.get_loc(ath_seg.idxmax())) if len(ath_seg) else 0

    atr = calculate_atr(df, 14)
    atr_val = float(atr.iloc[i]) if np.isfinite(atr.iloc[i]) else 0.0
    atr_ratio = atr_val / price if price > 0 else 0.0

    return {
        "breakout_pct": breakout_pct,
        "volume_surge": volume_surge,
        "close_strength": close_strength,
        "base_length": float(base_length),
        "volatility_contraction": volatility_contraction,
        "volume_dry_up": volume_dry_up,
        "ma200_slope": ma200_slope,
        "pct_above_52w_low": pct_above_52w_low,
        "rs_vs_market": rs_vs_market,
        "market_return": market_return,
        "ma20_deviation": ma20_deviation,
        "liquidity": liquidity,
        "days_since_ath": float(days_since_ath),
        "atr_ratio": atr_ratio,
    }
```

```python
"""F2 — D+1(익일 시가) 예측에 특화된 신규 피처 10개. 스펙 §5.2."""
from __future__ import annotations

import numpy as np
import pandas as pd

F2_NAMES = [
    "avg_gap_20d", "gap_vol_20d", "gap_open", "day_change",
    "intraday_range", "upper_shadow", "market_gap_prev", "dow",
    "aligned", "prior_surge_5d",
]

SURGE_LEVEL = 0.12   # '급등' 기준 (모의투자대회 backtest.py와 동일)


def compute_f2(df: pd.DataFrame, i: int, market: pd.DataFrame) -> dict:
    """봉 i의 F2 피처 10개."""
    o = df["Open"].astype(float)
    h = df["High"].astype(float)
    l = df["Low"].astype(float)
    c = df["Close"].astype(float)

    prev_close = float(c.iloc[i - 1])
    price = float(c.iloc[i])

    # 종목별 갭 성향: 최근 20봉의 (Open[t]/Close[t-1] - 1)
    gaps = (o.iloc[i - 19:i + 1].to_numpy() /
            c.iloc[i - 20:i].to_numpy()) - 1.0
    gaps = gaps[np.isfinite(gaps)]
    avg_gap_20d = float(gaps.mean()) if gaps.size else 0.0
    gap_vol_20d = float(gaps.std()) if gaps.size > 1 else 0.0

    gap_open = (float(o.iloc[i]) - prev_close) / prev_close if prev_close > 0 else 0.0
    day_change = (price - prev_close) / prev_close if prev_close > 0 else 0.0

    rng = float(h.iloc[i] - l.iloc[i])
    intraday_range = rng / prev_close if prev_close > 0 else 0.0
    upper_shadow = (float(h.iloc[i]) - price) / rng if rng > 0 else 0.0

    date = df.index[i]
    prev_date = df.index[i - 1]
    market_gap_prev = 0.0
    if market is not None and prev_date in market.index:
        val = market.loc[prev_date, "gap"]
        market_gap_prev = float(val) if np.isfinite(val) else 0.0

    ma20 = float(c.iloc[i - 19:i + 1].mean())
    ma60 = float(c.iloc[i - 59:i + 1].mean())
    aligned = 1.0 if (price > ma20 > ma60) else 0.0

    prior = c.iloc[i - 5:i].to_numpy() / c.iloc[i - 6:i - 1].to_numpy() - 1.0
    prior_surge_5d = 1.0 if np.any(prior >= SURGE_LEVEL) else 0.0

    return {
        "avg_gap_20d": avg_gap_20d,
        "gap_vol_20d": gap_vol_20d,
        "gap_open": gap_open,
        "day_change": day_change,
        "intraday_range": intraday_range,
        "upper_shadow": upper_shadow,
        "market_gap_prev": market_gap_prev,
        "dow": float(date.dayofweek),
        "aligned": aligned,
```

```python
# -*- coding: utf-8 -*-
"""F3 — Microsoft qlib Alpha158 계열 피처 20개. 스펙 §5.3.

원 정의: https://github.com/microsoft/qlib — qlib/contrib/data/loader.py 의
Alpha158DL.get_feature_config(). KBAR 9종은 원식 그대로, 롤링은 d=20 창의
11종을 옮겼다. 0으로 나누는 경우 qlib과 동일하게 분모에 1e-12를 더한다.
"""
from __future__ import annotations

import numpy as np
import pandas as pd

EPS = 1e-12
WINDOW = 20

KBAR_NAMES = ["KMID", "KLEN", "KMID2", "KUP", "KUP2",
              "KLOW", "KLOW2", "KSFT", "KSFT2"]
ROLL_NAMES = [f"{n}_{WINDOW}" for n in
              ["RSV", "CORR", "CORD", "CNTP", "SUMP",
               "WVMA", "VSTD", "BETA", "RSQR", "IMAX", "QTLU"]]
F3_NAMES = KBAR_NAMES + ROLL_NAMES


def _kbar(o: float, h: float, l: float, c: float) -> dict:
    """qlib Alpha158 KBAR 9종."""
    hl = (h - l) + EPS
    return {
        "KMID": (c - o) / (o + EPS),
        "KLEN": (h - l) / (o + EPS),
        "KMID2": (c - o) / hl,
        "KUP": (h - max(o, c)) / (o + EPS),
        "KUP2": (h - max(o, c)) / hl,
        "KLOW": (min(o, c) - l) / (o + EPS),
        "KLOW2": (min(o, c) - l) / hl,
        "KSFT": (2 * c - h - l) / (o + EPS),
        "KSFT2": (2 * c - h - l) / hl,
    }


def _safe(x: float) -> float:
    return float(x) if np.isfinite(x) else 0.0


def compute_f3(df: pd.DataFrame, i: int) -> dict:
    """봉 i의 F3 피처 20개 (KBAR 9 + 롤링 11, 창 20)."""
    o = float(df["Open"].iloc[i])
    h = float(df["High"].iloc[i])
    l = float(df["Low"].iloc[i])
    c = float(df["Close"].iloc[i])

    out = {k: _safe(v) for k, v in _kbar(o, h, l, c).items()}

    d = WINDOW
    lo = max(0, i - d + 1)
    close = df["Close"].iloc[lo:i + 1].to_numpy(dtype=float)
    high = df["High"].iloc[lo:i + 1].to_numpy(dtype=float)
    low = df["Low"].iloc[lo:i + 1].to_numpy(dtype=float)
    vol = df["Volume"].iloc[lo:i + 1].to_numpy(dtype=float)
    n = len(close)

    # RSV: 창 내 저가~고가 사이 종가 위치
    rsv = (c - low.min()) / ((high.max() - low.min()) + EPS)

    logv = np.log1p(np.maximum(vol, 0.0))
    corr = np.corrcoef(close, logv)[0, 1] if n > 1 and close.std() > 0 and logv.std() > 0 else 0.0

    dc = np.diff(close) / (close[:-1] + EPS)
    dv = np.diff(logv)
    cord = (np.corrcoef(dc, dv)[0, 1]
            if len(dc) > 1 and dc.std() > 0 and dv.std() > 0 else 0.0)

    cntp = float((dc > 0).mean()) if len(dc) else 0.0
    gains = np.maximum(dc, 0.0).sum()
    total = np.abs(dc).sum()
    sump = gains / (total + EPS)

    wvma = (np.std(dc * vol[1:]) / (np.mean(np.abs(dc * vol[1:])) + EPS)
            if len(dc) else 0.0)
    vstd = vol.std() / (vol.mean() + EPS)

    x = np.arange(n, dtype=float)
    if n > 1 and close.std() > 0:
        slope, intercept = np.polyfit(x, close, 1)
        pred = slope * x + intercept
        ss_res = float(((close - pred) ** 2).sum())
        ss_tot = float(((close - close.mean()) ** 2).sum())
        rsqr = 1.0 - ss_res / (ss_tot + EPS)
    else:
        slope, rsqr = 0.0, 0.0

    imax = float(n - 1 - int(np.argmax(high))) / d
    qtlu = float(np.quantile(close, 0.8)) / (c + EPS)

    out.update({
        f"RSV_{d}": _safe(rsv),
        f"CORR_{d}": _safe(corr),
        f"CORD_{d}": _safe(cord),
        f"CNTP_{d}": _safe(cntp),
        f"SUMP_{d}": _safe(sump),
        f"WVMA_{d}": _safe(wvma),
        f"VSTD_{d}": _safe(vstd),
        f"BETA_{d}": _safe(slope / (c + EPS)),
        f"RSQR_{d}": _safe(rsqr),
        f"IMAX_{d}": _safe(imax),
        f"QTLU_{d}": _safe(qtlu),
    })
    return out
```

```python
# -*- coding: utf-8 -*-
"""F4 — 재료 피처 5개. 스펙 §5.4.

핵심 제약: type_prior와 TF-IDF 인덱스는 **학습 구간 데이터만으로** 만든다.
전역 상수(CATALYST_TYPE_PRIOR)를 쓰면 미래정보 누수이므로 쓰지 않는다.
원 아이디어: 모의투자대회/catalyst_engine/baserate.py (char n-gram TF-IDF).
"""
from __future__ import annotations

import numpy as np
import pandas as pd

F4_NAMES = ["type_prior", "analog_mean_d1", "analog_win_rate",
            "analog_n", "reason_len"]

NEUTRAL = {"type_prior": 0.0, "analog_mean_d1": 0.0,
           "analog_win_rate": 0.5, "analog_n": 0.0, "reason_len": 0.0}


class CatalystIndex:
    """학습 구간 재료 데이터로만 만든 prior + 유사사례 검색기."""

    def __init__(self) -> None:
        self._fitted = False
        self._type_mean: dict[str, float] = {}
        self._global_mean = 0.0
        self._vec = None
        self._mat = None
        self._d1 = np.array([])

    def fit(self, rows: pd.DataFrame) -> "CatalystIndex":
        """rows: 컬럼 ctype, reason, d1 (학습 구간만 넘길 것)."""
        from sklearn.feature_extraction.text import TfidfVectorizer

        r = rows.dropna(subset=["d1"]).copy()
        r["reason"] = r["reason"].fillna("").astype(str)
        r = r[r["reason"].str.len() > 0]

        self._global_mean = float(r["d1"].mean()) if len(r) else 0.0
        self._type_mean = r.groupby("ctype")["d1"].mean().to_dict()
        self._d1 = r["d1"].to_numpy(dtype=float)

        if len(r) >= 2:
            self._vec = TfidfVectorizer(analyzer="char_wb", ngram_range=(2, 4),
                                        min_df=1, sublinear_tf=True)
            self._mat = self._vec.fit_transform(r["reason"].tolist())
        self._fitted = True
        return self

    def transform(self, ctype, reason, k: int = 10) -> dict:
        """재료 유형·사유 → F4 피처 5개. 재료가 없으면 중립값."""
        if not self._fitted:
            raise RuntimeError("CatalystIndex.fit()을 먼저 호출해야 한다")
        if not reason or (isinstance(reason, float) and np.isnan(reason)):
            return dict(NEUTRAL)

        reason = str(reason)
        out = dict(NEUTRAL)
        out["type_prior"] = float(self._type_mean.get(ctype, self._global_mean))
        out["reason_len"] = float(len(reason))

        if self._mat is not None:
            from sklearn.metrics.pairwise import cosine_similarity

            sims = cosine_similarity(self._vec.transform([reason]), self._mat)[0]
            kk = int(min(k, len(sims)))
            idx = np.argsort(-sims)[:kk]
            vals = self._d1[idx]
            if vals.size:
                out["analog_mean_d1"] = float(vals.mean())
                out["analog_win_rate"] = float((vals > 0).mean())
                out["analog_n"] = float(vals.size)
        return out


def attach_catalyst(events: pd.DataFrame, cat: pd.DataFrame) -> pd.DataFrame:
    """이벤트에 (date, code) 기준으로 재료를 left join한다."""
    c = cat[["date", "code", "ctype", "reason", "d1"]].drop_duplicates(
        subset=["date", "code"], keep="first")
    out = events.merge(c, on=["date", "code"], how="left")
    out["has_catalyst"] = out["reason"].notna().astype(int)
    return out
```

```python
# -*- coding: utf-8 -*-
"""F5 — 투자자 수급 피처 6개.

출처: scripts/collect_investor.py 가 키움 ka10059로 수집한 data/investor.pkl.
한국 시장의 익일 수익률 예측에서 수급은 가장 유력한 후보 변수지만, 전 기간을 주는
경로가 키움뿐이었다(KRX 404 · KIS 30일 · 로컬캐시 3개월).

pickle 사용 주의: 이 프로젝트가 직접 수집해 쓴 1st-party 파일이다.

단위: 수집 시 unit_tp=1000 이라 순매수는 천 단위다. 종목 규모 차이가 수십~수억 배라
절대값을 그대로 쓰면 안 되고, 반드시 거래대금으로 나눠 무차원화한다.
결측은 0이 아니라 NaN으로 둔다 - 0은 "순매수가 정확히 0"이라는 다른 정보다.
"""
from __future__ import annotations

import pickle

import numpy as np
import pandas as pd

from surge_d1 import config

F5_NAMES = ["foreign_net_1d", "foreign_net_5d", "inst_net_1d",
            "inst_net_5d", "indiv_net_5d", "foreign_streak"]

NAN = {k: float("nan") for k in F5_NAMES}
STREAK_CLIP = 10


def load_investor() -> dict[str, pd.DataFrame]:
    """code → 수급 이력. 파일이 없으면 빈 dict(수급 없이 진행)."""
    path = config.PROJECT_ROOT / "data" / "investor.pkl"
    if not path.exists():
        return {}
    with open(path, "rb") as f:
        store = pickle.load(f)
    out = {}
    for code, df in store.items():
        if df is None or len(df) == 0:
            continue
        d = df.copy()
        d["date"] = pd.to_datetime(d["date"])
        out[code] = d.sort_values("date").reset_index(drop=True)
    return out


def _ratio(num: float, den: float) -> float:
    """거래대금 대비 비율. 분모가 0/결측이면 NaN."""
    if not np.isfinite(den) or den == 0:
        return float("nan")
    return float(num) / float(den)


def compute_f5(inv: pd.DataFrame | None, date: pd.Timestamp) -> dict:
    """조회일(date) **이하** 구간만 보고 수급 피처를 만든다.

    date 이후 행은 미래정보이므로 반드시 잘라낸다.
    """
    if inv is None or len(inv) == 0:
        return dict(NAN)

    past = inv[inv["date"] <= date]
    if len(past) == 0:
        return dict(NAN)
    # 조회일 당일 데이터가 없으면(휴장·결측) 1일 피처는 NaN
    same_day = past[past["date"] == date]

    out = dict(NAN)

    if len(same_day):
        r = same_day.iloc[-1]
        out["foreign_net_1d"] = _ratio(r["foreign"], r["trd_value"])
        out["inst_net_1d"] = _ratio(r["inst"], r["trd_value"])

    w = past.tail(5)
    den5 = float(w["trd_value"].sum())
    if len(w) and np.isfinite(den5) and den5 > 0:
        out["foreign_net_5d"] = float(w["foreign"].sum()) / den5
        out["inst_net_5d"] = float(w["inst"].sum()) / den5
        out["indiv_net_5d"] = float(w["indiv"].sum()) / den5

    # 연속 순매수(양수) / 순매도(음수) 일수
    vals = past["foreign"].to_numpy(dtype=float)[::-1]
    streak = 0
    if len(vals) and np.isfinite(vals[0]) and vals[0] != 0:
        sign = 1 if vals[0] > 0 else -1
        for v in vals:
            if not np.isfinite(v) or v == 0 or (1 if v > 0 else -1) != sign:
                break
            streak += 1
        streak *= sign
    out["foreign_streak"] = float(np.clip(streak, -STREAK_CLIP, STREAK_CLIP))
    return out
```

```python
def add_sample_weight(df: pd.DataFrame) -> pd.DataFrame:
    """같은 날 이벤트들이 시장 충격을 공유하므로 1/(그날 건수)로 가중. 스펙 §7.3."""
```

```python
# -*- coding: utf-8 -*-
"""검증 프로토콜: walk-forward + embargo, 지표, 통계검정. 스펙 §7.2, §7.5."""
from __future__ import annotations

import numpy as np
import pandas as pd
from scipy import stats

from surge_d1 import config


def walk_forward_folds(dates: pd.Series, test_years: list[int],
                       embargo_days: int = config.EMBARGO_DAYS
                       ) -> list[tuple[np.ndarray, np.ndarray]]:
    """expanding window walk-forward. 반환: [(train_mask, test_mask), ...]

    학습은 검정연도 시작 이전 전체에서 embargo_days(달력일) 만큼을 더 잘라낸다.
    """
    d = pd.to_datetime(pd.Series(dates).reset_index(drop=True))
    folds = []
    for y in sorted(test_years):
        start = pd.Timestamp(f"{y}-01-01")
        end = pd.Timestamp(f"{y}-12-31 23:59:59")
        test = (d >= start) & (d <= end)
        cutoff = start - pd.Timedelta(days=embargo_days)
        train = d < cutoff
        if train.sum() == 0 or test.sum() == 0:
            continue
        folds.append((train.to_numpy(), test.to_numpy()))
    return folds


def spearman_ic(y_true, y_pred, dates) -> tuple[float, float]:
    """일별 Spearman 순위상관의 평균과 t값(=IR 근사)."""
    df = pd.DataFrame({"y": np.asarray(y_true, dtype=float),
                       "p": np.asarray(y_pred, dtype=float),
                       "d": pd.to_datetime(pd.Series(dates).values)})
    ics = []
    for _, g in df.groupby("d"):
        if len(g) < 3 or g["p"].nunique() < 2 or g["y"].nunique() < 2:
            continue
        ic = stats.spearmanr(g["y"], g["p"]).statistic
        if np.isfinite(ic):
            ics.append(float(ic))
    if not ics:
        return 0.0, 0.0
    arr = np.array(ics)
    se = arr.std(ddof=1) / np.sqrt(len(arr)) if len(arr) > 1 else np.nan
    t = float(arr.mean() / se) if se and np.isfinite(se) and se > 0 else 0.0
    return float(arr.mean()), t


def top_decile_return(y_true, y_pred, dates, q: float = 0.1) -> float:
    """일별로 예측 상위 q 비율을 뽑아 실제 수익률 평균을 낸다."""
    df = pd.DataFrame({"y": np.asarray(y_true, dtype=float),
                       "p": np.asarray(y_pred, dtype=float),
                       "d": pd.to_datetime(pd.Series(dates).values)})
    picked = []
    for _, g in df.groupby("d"):
        k = max(1, int(round(len(g) * q)))
        picked.append(g.nlargest(k, "p")["y"])
    if not picked:
        return float("nan")
    return float(pd.concat(picked).mean())


def bootstrap_ci(values, n: int = 1000, seed: int = config.RANDOM_SEED,
                 alpha: float = 0.05) -> tuple[float, float]:
    """평균의 부트스트랩 신뢰구간."""
    v = np.asarray(values, dtype=float)
    v = v[np.isfinite(v)]
    if v.size == 0:
        return float("nan"), float("nan")
    rng = np.random.default_rng(seed)
    means = rng.choice(v, size=(n, v.size), replace=True).mean(axis=1)
    return (float(np.quantile(means, alpha / 2)),
            float(np.quantile(means, 1 - alpha / 2)))


def permutation_pvalue(metric_fn, y, pred_a, pred_b, dates,
                       n: int = 1000, seed: int = config.RANDOM_SEED) -> float:
    """H0: pred_b가 pred_a보다 낫지 않다.

    관측 차이(metric(b) - metric(a))가, b의 예측을 무작위 섞었을 때의 분포에서
    얼마나 극단적인지로 p값을 낸다.
    """
    y = np.asarray(y, dtype=float)
    a = np.asarray(pred_a, dtype=float)
    b = np.asarray(pred_b, dtype=float)
    observed = metric_fn(y, b, dates) - metric_fn(y, a, dates)
    rng = np.random.default_rng(seed)
    cnt = 0
    for _ in range(n):
        shuffled = rng.permutation(b)
        diff = metric_fn(y, shuffled, dates) - metric_fn(y, a, dates)
        if diff >= observed:
            cnt += 1
    return (cnt + 1) / (n + 1)


def benjamini_hochberg(pvals: list[float]) -> list[float]:
    """BH 보정 p값. 입력 순서를 유지해 반환한다."""
    p = np.asarray(pvals, dtype=float)
    m = p.size
    order = np.argsort(p)
    ranked = p[order]
    adj = ranked * m / (np.arange(m) + 1)
    adj = np.minimum.accumulate(adj[::-1])[::-1]
    adj = np.clip(adj, 0.0, 1.0)
    out = np.empty(m, dtype=float)
    out[order] = adj
    return out.tolist()
```

```python
# -*- coding: utf-8 -*-
"""M0~M5 학습·평가와 ablation 실행. 스펙 §7.1, §7.4, §7.6."""
from __future__ import annotations

import sys

import numpy as np
import pandas as pd
from sklearn.isotonic import IsotonicRegression
from sklearn.metrics import brier_score_loss, roc_auc_score
from sklearn.model_selection import KFold

from surge_d1 import config, dataset, features_f4, validate

REG_PARAMS = dict(n_estimators=200, max_depth=3, learning_rate=0.01,
                  subsample=0.8, reg_alpha=1.0, reg_lambda=5.0,
                  random_state=config.RANDOM_SEED, verbose=-1, n_jobs=-1)
CLF_PARAMS = dict(n_estimators=200, max_depth=5, learning_rate=0.05,
                  subsample=0.8, colsample_bytree=0.8,
                  random_state=config.RANDOM_SEED, verbose=-1, n_jobs=-1)

TEST_YEARS = [2023, 2024, 2025, 2026]


def fit_predict(train_df: pd.DataFrame, test_df: pd.DataFrame,
                feats: list[str], use_weight: bool = True,
                label_reg: str = "y_raw") -> dict:
    """회귀·분류 학습 후 예측. feats가 비면 M0(상수 예측)."""
    n_test = len(test_df)
    if not feats:
        base_ret = float(train_df[label_reg].mean())
        base_p = float(train_df["y_cls"].mean())
        return {"pred_reg": np.full(n_test, base_ret),
                "prob_raw": np.full(n_test, base_p),
                "prob_cal": np.full(n_test, base_p)}

    from lightgbm import LGBMClassifier, LGBMRegressor

    Xtr = train_df[feats].to_numpy(dtype=float)
    Xte = test_df[feats].to_numpy(dtype=float)
    w = train_df["weight"].to_numpy(dtype=float) if use_weight else None

    reg = LGBMRegressor(**REG_PARAMS)
    reg.fit(Xtr, train_df[label_reg].to_numpy(dtype=float), sample_weight=w)
    pred_reg = reg.predict(Xte)

    clf = LGBMClassifier(**CLF_PARAMS)
    ytr = train_df["y_cls"].to_numpy(dtype=int)
    clf.fit(Xtr, ytr, sample_weight=w)
    prob_raw = clf.predict_proba(Xte)[:, 1]

    # 확률 보정: 학습 구간 내부 예측으로 isotonic을 적합 (스펙 §7.4)
    prob_tr = clf.predict_proba(Xtr)[:, 1]
    iso = IsotonicRegression(out_of_bounds="clip", y_min=0.0, y_max=1.0)
    iso.fit(prob_tr, ytr)
    prob_cal = np.clip(iso.predict(prob_raw), 0.0, 1.0)

    return {"pred_reg": pred_reg, "prob_raw": prob_raw, "prob_cal": prob_cal}


def evaluate(test_df: pd.DataFrame, out: dict,
             label_reg: str = "y_raw") -> dict:
    """검정 구간 지표. 스펙 §7.5."""
    y = test_df[label_reg].to_numpy(dtype=float)
    ycls = test_df["y_cls"].to_numpy(dtype=int)
    dates = test_df["date"]

    if len(np.unique(ycls)) < 2:
        auc = float("nan")
    else:
        auc = float(roc_auc_score(ycls, out["prob_cal"]))
    brier = float(brier_score_loss(ycls, out["prob_cal"]))
    ic, ic_t = validate.spearman_ic(y, out["pred_reg"], dates)
    top = validate.top_decile_return(y, out["pred_reg"], dates)
    return {"auc": auc, "brier": brier, "ic": ic, "ic_t": ic_t,
            "top_decile": top, "n": int(len(test_df))}


def _build_f4(train_df: pd.DataFrame, test_df: pd.DataFrame
              ) -> tuple[pd.DataFrame, pd.DataFrame]:
    """폴드 학습 구간만으로 CatalystIndex를 적합해 F4를 만든다. 스펙 §5.4."""
    idx = features_f4.CatalystIndex().fit(
        train_df.loc[train_df["has_catalyst"] == 1, ["ctype", "reason", "d1"]])

    def apply(df):
        rows = [idx.transform(r.ctype, r.reason)
                for r in df.itertuples(index=False)]
        return pd.concat([df.reset_index(drop=True),
                          pd.DataFrame(rows)], axis=1)

    return apply(train_df), apply(test_df)


def run_ablation(df: pd.DataFrame) -> pd.DataFrame:
    """M0~M4는 전체 표본 4폴드, M4prime/M5는 재료 표본 단일 폴드."""
    results = []

    folds = validate.walk_forward_folds(df["date"], TEST_YEARS)
    for fi, (tr_mask, te_mask) in enumerate(folds, 1):
        tr, te = df[tr_mask].reset_index(drop=True), df[te_mask].reset_index(drop=True)
        year = int(te["date"].dt.year.mode()[0])
        for name in ("M0", "M1", "M2", "M3", "M4"):
            feats = [] if name == "M0" else dataset.FEATURE_SETS[name]
            out = fit_predict(tr, te, feats)
            results.append({"model": name, "fold": fi, "test_year": year,
                            "sample": "full", **evaluate(te, out)})
            print(f"  {name} fold{fi}({year}) 완료", flush=True)

    # 재료 표본: M4prime vs M5
    #
    # ⚠️ 표본 대비 피처가 많다. 재료가 붙은 이벤트는 약 1,800건인데 M5는 피처 55개라
    # 학습 구간이 1,000행 남짓이면 과적합이 사실상 확정이다. 그렇다고 이 폴드만
    # 하이퍼파라미터를 조이면 M4와 비교가 깨진다 — **파라미터는 고정한 채 두고,
    # 표본 크기(n)를 결과표와 리포트에 크게 적어 결론의 강도를 스스로 낮춘다.**
    # M5가 M4prime을 이겨도 이 표본에서는 잠정적 증거일 뿐이다.
    cat = df[df["has_catalyst"] == 1].reset_index(drop=True)
    if len(cat) > 200:
        split = cat["date"].quantile(0.6)
        tr = cat[cat["date"] < split].reset_index(drop=True)
        te = cat[cat["date"] >= split].reset_index(drop=True)
        tr4, te4 = _build_f4(tr, te)
        for name, feats in (("M4prime", dataset.FEATURE_SETS["M4"]),
                            ("M5", dataset.FEATURE_SETS["M5"])):
            out = fit_predict(tr4, te4, feats)
            results.append({"model": name, "fold": 1,
                            "test_year": int(te["date"].dt.year.min()),
                            "sample": "catalyst", **evaluate(te4, out)})
            print(f"  {name} (재료 표본) 완료", flush=True)

    return pd.DataFrame(results)


def run_leakage_comparison(df: pd.DataFrame) -> pd.DataFrame:
    """같은 데이터를 셔플 CV와 walk-forward로 평가해 편향을 잰다. 스펙 §7.6."""
    feats = dataset.FEATURE_SETS["M1"]
    rows = []

    kf = KFold(n_splits=5, shuffle=True, random_state=config.RANDOM_SEED)
    aucs, ics = [], []
    for tr_i, te_i in kf.split(df):
        tr = df.iloc[tr_i].reset_index(drop=True)
        te = df.iloc[te_i].reset_index(drop=True)
        m = evaluate(te, fit_predict(tr, te, feats))
        aucs.append(m["auc"])
        ics.append(m["ic"])
    rows.append({"method": "shuffle_kfold", "auc": float(np.nanmean(aucs)),
                 "ic": float(np.nanmean(ics))})

    aucs, ics = [], []
    for tr_mask, te_mask in validate.walk_forward_folds(df["date"], TEST_YEARS):
        tr = df[tr_mask].reset_index(drop=True)
        te = df[te_mask].reset_index(drop=True)
        m = evaluate(te, fit_predict(tr, te, feats))
        aucs.append(m["auc"])
        ics.append(m["ic"])
    rows.append({"method": "walk_forward", "auc": float(np.nanmean(aucs)),
                 "ic": float(np.nanmean(ics))})

    out = pd.DataFrame(rows)
    out["auc_bias"] = out["auc"] - out["auc"].iloc[1]
    return out


def main() -> int:
    sys.stdout.reconfigure(encoding="utf-8")
    df = pd.read_parquet(config.DATASET_PATH)
    config.RESULTS_DIR.mkdir(parents=True, exist_ok=True)

    print("=== ablation (M0~M5) ===")
    ab = run_ablation(df)
    ab.to_csv(config.RESULTS_DIR / "ablation.csv", index=False, encoding="utf-8-sig")
    print(ab.groupby("model")[["auc", "ic", "top_decile"]].mean().to_string())

    print("\n=== 누수 편향 비교 ===")
    lk = run_leakage_comparison(df)
    lk.to_csv(config.RESULTS_DIR / "leakage.csv", index=False, encoding="utf-8-sig")
    print(lk.to_string(index=False))
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

알파의 실제 효용은 **동일 자본으로 굴렸을 때의 누적수익·샤프·MDD**로만 판단할 수 있고,
비교군이 있어야 "모델이 고른 것"과 "그냥 다 산 것"의 차이를 말할 수 있다.

**비교 전략 4종** (모두 종가 매수 → 익일 시가 매도, 왕복비용 0.21% 포함된 `y_raw` 사용):

| 전략 | 정의 |
|---|---|
| `model_top5` | 그날 돌파 종목 중 모델 예측 상위 5개 균등 매수 |
| `model_top10` | 상위 10개 균등 매수 |
| `all_breakouts` | 그날 돌파 종목 **전부** 균등 매수 (= 이벤트 자체의 알파, 모델 없음) |
| **`rule_top5_close`** | **마감강도(`close_strength`) 상위 5개 — 실측상 가장 강한 단일 지표** |
| `random_n` | 그날 돌파 종목 중 **무작위** 5개 (시드 고정 20회 반복 평균) |
| `market` | 시장 등가중 벤치마크 — 같은 날짜 축의 전 종목 평균 익일 시가 수익률 |

`model_*` 가 `all_breakouts` 를 못 이기면 "모델은 무용하고 이벤트만 유효하다"는 결론이고,
`all_breakouts` 가 `market` 근처면 "이벤트도 무용"이다. 어느 쪽이든 발표 가능한 결과다.

⚠️ **가장 중요한 대조군은 `rule_top5_close` 다.** Task 11 실측(2026 폴드, n=4,277)에서
상위10% 수익률이 **모델(피처 50개) 5.344% 대 `close_strength` 단독 정렬 4.998%** 로,
ML의 상대 기여가 **7%에 불과**했다(무작위 0.782%, 완벽예측 상한 10.794%).
즉 알파의 대부분이 이벤트 정의와 마감강도라는 단일 지표에 있다. 백테스트가 이를
확인하면 그것이 이 연구의 핵심 결론이며, "모델이 좋다"보다 정직하고 강한 발견이다.

```python
    assert d.loc[pd.Timestamp("2024-01-02"), "ret"] == pytest.approx(0.03)

def test_simulate_전부매수는_그날_평균이다():

    assert d.iloc[0]["ret"] == pytest.approx((0.04 + 0.02 - 0.01 - 0.03) / 4)
    assert d.iloc[0]["n_picked"] == 4

        {"ret": [0.10, 0.10], "n_picked": [1, 1]},

    )
    s = backtest.performance_stats(daily)
    assert s["cum_return"] == pytest.approx(0.21)      # 1.1*1.1 - 1
```

```python
# -*- coding: utf-8 -*-
"""전략 백테스트: 모델 픽 vs 전부매수 vs 무작위.

상위 decile 평균 수익률은 자본배분·복리·낙폭을 뺀 숫자라 알파의 효용을 말해주지
못한다. 여기서는 같은 자본으로 굴렸을 때의 누적수익·샤프·MDD를 비교한다.

수익률은 이미 왕복비용(0.21%)이 차감된 y_raw 를 쓴다. 즉 '종가 매수 → 익일 시가 매도'
1회전이 하루 수익률이며, 매일 전액 재투자한다고 가정한다.
"""
from __future__ import annotations

import sys

import numpy as np
import pandas as pd

from surge_d1 import config

TRADING_DAYS = 252


def simulate(df: pd.DataFrame, score_col: str,
             top_n: int | None) -> pd.DataFrame:
    """날짜별로 score 상위 top_n을 균등 매수한 포트폴리오의 일별 수익률.

    top_n=None 이면 그날 후보 전부를 균등 매수한다.
    후보 수가 top_n보다 적으면 있는 만큼만 산다(현금 보유 없음, 균등 배분).
    """
    rows = []
    for date, g in df.groupby("date"):
        picked = g if top_n is None else g.nlargest(top_n, score_col)
        if len(picked) == 0:
            continue
        rows.append({"date": date,
                     "ret": float(picked["y_raw"].mean()),
                     "n_picked": int(len(picked))})
    out = pd.DataFrame(rows)
    if len(out) == 0:
        return pd.DataFrame({"ret": [], "n_picked": []},
                            index=pd.to_datetime([]))
    return out.set_index("date").sort_index()


def simulate_random(df: pd.DataFrame, top_n: int, n_iter: int = 20,
                    seed: int = config.RANDOM_SEED) -> pd.DataFrame:
    """무작위 top_n 선택을 n_iter회 반복한 평균 일별 수익률(비교군)."""
    rng = np.random.default_rng(seed)
    acc = None
    for _ in range(n_iter):
        rows = []
        for date, g in df.groupby("date"):
            k = min(top_n, len(g))
            if k == 0:
                continue
            idx = rng.choice(len(g), size=k, replace=False)
            rows.append({"date": date,
                         "ret": float(g["y_raw"].to_numpy()[idx].mean()),
                         "n_picked": int(k)})
        cur = pd.DataFrame(rows).set_index("date").sort_index()
        acc = cur if acc is None else acc.add(cur, fill_value=0.0)
    if acc is None:
        return pd.DataFrame({"ret": [], "n_picked": []},
                            index=pd.to_datetime([]))
    acc["ret"] /= n_iter
    acc["n_picked"] /= n_iter
    return acc


def _empty_stats() -> dict:
    keys = ("cum_return cagr vol sharpe sortino calmar mdd mdd_days win_rate "
            "profit_factor expectancy sqn best_day worst_day alpha beta").split()
    out = {k: float("nan") for k in keys}
    out.update({"cum_return": 0.0, "cagr": 0.0, "vol": 0.0, "mdd": 0.0,
                "mdd_days": 0, "n_days": 0, "n_trades": 0})
    return out


def _max_drawdown_days(equity: pd.Series) -> int:
    """최대낙폭이 지속된 기간(거래일).

    backtrader DrawDown 분석기 방식: 고점 대비 낙폭 상태가 이어진 봉 수를 세고
    낙폭이 0이 되면 리셋한다. 그중 최댓값을 돌려준다.
    """
    peak = equity.cummax()
    under = (equity < peak).to_numpy()
    best = cur = 0
    for flag in under:
        cur = cur + 1 if flag else 0
        best = max(best, cur)
    return int(best)


def performance_stats(daily: pd.DataFrame,
                      benchmark: pd.Series | None = None,
                      risk_free: float = 0.0) -> dict:
    """일별 수익률 → 성과 지표. 매일 전액 재투자(복리) 가정.

    지표 정의는 공개 라이브러리를 그대로 따랐다(자의적 공식이 아님):
      - Sortino / Calmar / Alpha / Beta : vectorbt `vectorbt/returns/nb.py`
      - MDD 지속일수                    : backtrader `analyzers/drawdown.py`
      - SQN                             : backtrader `analyzers/sqn.py` (Van K. Tharp)

    risk_free 는 **연율**로 받아 기하적으로 일할 환산한다(backtrader convertrate 방식):
        일간 무위험수익률 = (1 + 연율)^(1/252) - 1
    기본값 0인 이유: 이 전략은 하룻밤만 시장에 노출되고 나머지 시간은 현금이라
    무위험수익률을 빼는 것이 오히려 과도한 페널티다. 민감도는 리포트에 별도 표기한다.
    """
    r = daily["ret"].astype(float).dropna() if len(daily) else pd.Series(dtype=float)
    n = len(r)
    if n == 0:
        return _empty_stats()

    rf_daily = (1.0 + risk_free) ** (1.0 / TRADING_DAYS) - 1.0
    excess = r - rf_daily

    equity = (1.0 + r).cumprod()
    cum_return = float(equity.iloc[-1] - 1.0)
    # 연환산 수익률: (∏(1+r))^(252/n) - 1   (vectorbt annualized_return)
    cagr = float(equity.iloc[-1] ** (TRADING_DAYS / n) - 1.0)

    sd = float(r.std(ddof=1)) if n > 1 else 0.0     # 표본 표준편차(Bessel)
    vol = sd * np.sqrt(TRADING_DAYS)
    sharpe = (float(excess.mean() / sd * np.sqrt(TRADING_DAYS))
              if sd > 0 else float("nan"))

    # Sortino: 하방편차의 평균은 **전체 관측치**로 나눈다(vectorbt downside_risk)
    downside = np.minimum(excess.to_numpy(), 0.0)
    dd_risk = float(np.sqrt(np.mean(downside ** 2)) * np.sqrt(TRADING_DAYS))
    sortino = (float(excess.mean() * TRADING_DAYS / dd_risk)
               if dd_risk > 0 else float("nan"))

    peak = equity.cummax()
    mdd = float((1.0 - equity / peak).max())
    calmar = float(cagr / mdd) if mdd > 0 else float("nan")

    wins, losses = r[r > 0], r[r < 0]
    gross_win, gross_loss = float(wins.sum()), float(-losses.sum())
    profit_factor = gross_win / gross_loss if gross_loss > 0 else float("nan")

    # SQN = √N × mean/std  (N<30이면 신뢰 불가 → NaN)
    sqn = float(np.sqrt(n) * r.mean() / sd) if (sd > 0 and n >= 30) else float("nan")

    alpha = beta = float("nan")
    if benchmark is not None:
        b = benchmark.reindex(r.index).astype(float)
        mask = b.notna() & r.notna()
        if mask.sum() > 2:
            rr, bb = r[mask].to_numpy(), b[mask].to_numpy()
            bres = bb - bb.mean()
            var_b = float(np.mean(bres ** 2))
            if var_b > 0:
                beta = float(np.mean(bres * rr) / var_b)
                a_series = (rr - rf_daily) - beta * (bb - rf_daily)
                alpha = float((np.mean(a_series) + 1.0) ** TRADING_DAYS - 1.0)

    return {
        "cum_return": cum_return, "cagr": cagr, "vol": vol,
        "sharpe": sharpe, "sortino": sortino, "calmar": calmar,
        "mdd": mdd, "mdd_days": _max_drawdown_days(equity),
        "win_rate": float((r > 0).mean()),
        "profit_factor": profit_factor,
        "expectancy": float(r.mean()),
        "sqn": sqn,
        "best_day": float(r.max()), "worst_day": float(r.min()),
        "alpha": alpha, "beta": beta,
        "n_days": int(n), "n_trades": int(daily["n_picked"].sum()),
    }


def out_of_sample_predictions(df: pd.DataFrame) -> pd.DataFrame:
    """walk-forward 폴드별 검정 구간 예측만 모아 이어 붙인다.

    학습 구간 예측으로 백테스트하면 전부 거짓이므로 반드시 이 경로를 쓴다.
    """
    from surge_d1 import dataset, models, validate

    feats = dataset.FEATURE_SETS["M4"]
    parts = []
    for tr_mask, te_mask in validate.walk_forward_folds(df["date"],
                                                        models.TEST_YEARS):
        tr = df[tr_mask].reset_index(drop=True)
        te = df[te_mask].reset_index(drop=True)
        out = models.fit_predict(tr, te, feats)
        te = te.copy()
        te["score"] = out["prob_cal"]
        te["pred_ret"] = out["pred_reg"]

        # 분위수 임계값은 **학습 구간 예측**으로 정한다. 검정 구간 예측으로 정하면
        # 결과를 보고 고르는 셈이라 체리피킹이다.
        tr_out = models.fit_predict(tr, tr, feats)
        thr = float(np.quantile(tr_out["prob_cal"], 0.80))
        te["pick_q80"] = (te["score"] >= thr).astype(int)

        parts.append(te)
    if not parts:
        return df.head(0).assign(score=[], pred_ret=[], pick_q80=[])
    return pd.concat(parts, ignore_index=True)


def simulate_threshold(df: pd.DataFrame, score_col: str,
                       threshold: float) -> pd.DataFrame:
    """score가 임계값 이상인 종목만 균등 매수. 조건 미달일이면 현금(수익률 0).

    **현금일을 빼면 안 된다.** 픽이 없는 날을 그냥 건너뛰면 거래일 수가 줄어 CAGR이
    부풀려지고, 자산곡선도 실제로 굴렸을 때와 달라진다. 조건이 까다로워 픽이 드물수록
    이 처리가 결과를 좌우한다.
    """
    rows = []
    for date, g in df.groupby("date"):
        picked = g[g[score_col] >= threshold]
        if len(picked) == 0:
            rows.append({"date": date, "ret": 0.0, "n_picked": 0})
        else:
            rows.append({"date": date, "ret": float(picked["y_raw"].mean()),
                         "n_picked": int(len(picked))})
    out = pd.DataFrame(rows)
    if len(out) == 0:
        return pd.DataFrame({"ret": [], "n_picked": []},
                            index=pd.to_datetime([]))
    return out.set_index("date").sort_index()


def tick_size(price: float) -> float:
    """KRX 호가단위(2023-01 개정). 슬리피지 1틱을 금액으로 환산할 때 쓴다."""
    for cap, tick in ((2_000, 1), (5_000, 5), (20_000, 10), (50_000, 50),
                      (200_000, 100), (500_000, 500)):
        if price < cap:
            return float(tick)
    return 1_000.0


def cost_sensitivity(oos: pd.DataFrame, top_n: int = 5,
                     extra_costs=(0.0, 0.001, 0.002, 0.004)) -> pd.DataFrame:
    """비용을 더 물렸을 때 전략이 언제 무너지는지 본다.

    nautilus_trader 문서가 지적하듯, 일봉(OHLC) 백테스트는 실제 체결 상호작용을
    재현하지 못한다. 우리는 종가 매수·익일 시가 매도를 가정하는데 둘 다 동시호가라
    실제 체결가가 불리할 수 있다. 그래서 단일 비용 가정에 기대지 않고, 추가 비용을
    단계적으로 물려 **엣지가 사라지는 지점**을 보고한다.
    """
    rows = []
    for extra in extra_costs:
        adj = oos.copy()
        adj["y_raw"] = adj["y_raw"] - extra
        d = simulate(adj, "score", top_n)
        s = performance_stats(d)
        rows.append({"extra_cost": extra, "cum_return": s["cum_return"],
                     "cagr": s["cagr"], "sharpe": s["sharpe"],
                     "mdd": s["mdd"], "win_rate": s["win_rate"]})
    return pd.DataFrame(rows)


def market_benchmark(df: pd.DataFrame) -> pd.DataFrame:
    """벤치마크: 그날 이벤트 유무와 무관한 전 종목 등가중 익일 시가 수익률.

    FinRL 이 항상 지수(^DJI)와 나란히 보고하는 관행을 따른다 — 전략 수익률만
    단독으로 제시하면 시장이 좋아서 번 것인지 구분할 수 없다.
    """
    from surge_d1 import sources

    ohlcv = sources.load_ohlcv()
    mi = sources.build_market_index(ohlcv)
    gap = mi["gap"].dropna() - config.COST
    out = pd.DataFrame({"ret": gap, "n_picked": mi["n"].reindex(gap.index)})
    return out


def run_backtest(df: pd.DataFrame) -> tuple[pd.DataFrame, pd.DataFrame, pd.DataFrame]:
    """전략들을 out-of-sample 예측 위에서 시뮬레이션한다.

    반환: (성과표, 일별수익률표, 비용민감도표)
    """
    oos = out_of_sample_predictions(df)
    mkt = market_benchmark(df)

    # 메인 6종 — 그림 하나에 들어가고, 각각 다른 질문에 답한다
    strategies = {
        "market": mkt,                                     # 시장 하한선
        "all_breakouts": simulate(oos, "score", None),      # ML 없이 룰만
        "rule_top5_close": simulate(oos, "close_strength", 5),   # 단일 지표 (최강 대조군)
        "rule_top5_breakout": simulate(oos, "breakout_pct", 5),  # ML 없는 규칙 선별
        "random_5": simulate_random(oos, 5),                # 우연
        "model_prob50": simulate_threshold(oos, "score", 0.50),  # ML 임계값
        "model_top5": simulate(oos, "score", 5),            # ML 상위N (종목수 맞춤)
    }
    # 부록 — 계산은 하되 메인 그림에는 넣지 않는다
    appendix = {
        "model_prob55": simulate_threshold(oos, "score", 0.55),
        "model_ret_pos": simulate_threshold(oos, "pred_ret", 0.0),
        "model_top10": simulate(oos, "score", 10),
        "rule_top5_value": simulate(oos, "liquidity", 5),
        "model_q80": simulate_threshold(oos, "pick_q80", 1),   # 폴드별 학습구간 상위20%
    }
    strategies.update(appendix)
    bench = mkt["ret"]
    stats = pd.DataFrame(
        [{"strategy": k, **performance_stats(v, benchmark=bench)}
         for k, v in strategies.items()]
    )
    daily = pd.concat(
        [v["ret"].rename(k) for k, v in strategies.items()], axis=1
    ).sort_index()
    sens = cost_sensitivity(oos)
    return stats, daily, sens


def main() -> int:
    sys.stdout.reconfigure(encoding="utf-8")
    df = pd.read_parquet(config.DATASET_PATH)
    stats, daily, sens = run_backtest(df)
    config.RESULTS_DIR.mkdir(parents=True, exist_ok=True)
    stats.to_csv(config.RESULTS_DIR / "backtest_stats.csv",
                 index=False, encoding="utf-8-sig")
    daily.to_csv(config.RESULTS_DIR / "backtest_daily.csv",
                 encoding="utf-8-sig")
    sens.to_csv(config.RESULTS_DIR / "backtest_cost_sensitivity.csv",
                index=False, encoding="utf-8-sig")

    show = stats.copy()
    for c in ("cum_return", "cagr", "vol", "mdd", "win_rate", "alpha"):
        show[c] = (show[c] * 100).round(2)
    for c in ("sharpe", "sortino", "calmar", "sqn", "beta", "profit_factor"):
        show[c] = show[c].round(3)
    print(show[["strategy", "cum_return", "cagr", "vol", "mdd", "mdd_days",
                "sharpe", "sortino", "calmar", "sqn", "win_rate",
                "profit_factor", "alpha", "beta", "n_days"]].to_string(index=False))
    print("\n=== 비용 민감도 (model_top5) ===")
    print(sens.assign(**{c: (sens[c] * 100).round(2)
                         for c in ("extra_cost", "cum_return", "cagr",
                                   "mdd", "win_rate")}).to_string(index=False))
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
def fig_horizon(df: pd.DataFrame, path: Path) -> None:
    """지평 비교 — 왜 익일 시가청산인가.

    기존 프로젝트가 예측하던 '20일 내 최고 수익률'은 어느 날이 고점인지 사후에만 알 수
    있어 실현 불가능하다. 그 사실을 그림으로 보여주는 것이 이 figure의 목적이다.
    """
    setup_korean_font()
    cols = [("y_raw", "익일 시가청산", True),
            ("y_hold", "익일 종가청산", True),
            ("y_hold20", "20일 보유", True)]
    labels, means, ts, colors = [], [], [], []
    for c, name, tradable in cols:
        if c not in df.columns:
            continue
        x = df[c].dropna()
        if len(x) < 2:
            continue
        labels.append(f"{name}\n(n={len(x):,})")
        means.append(float(x.mean()) * 100)
        se = x.std() / np.sqrt(len(x))
        ts.append(float(x.mean() / se) if se > 0 else 0.0)
        colors.append("#4C78A8" if tradable else "#BAB0AC")

    fig, axes = plt.subplots(1, 2, figsize=(12, 4.5))
    axes[0].bar(labels, means,
                color=["#E45756" if m < 0 else c for m, c in zip(means, colors)])
    axes[0].axhline(0, color="#888", lw=1)
    axes[0].set_title("지평별 평균 순수익률 (%)")
    axes[1].bar(labels, ts, color=colors)
    axes[1].axhline(0, color="#888", lw=1)
    axes[1].axhline(2, color="#E45756", ls="--", lw=1, label="t=2 (유의성 기준)")
    axes[1].set_title("지평별 t값 — 신호의 강도")
    axes[1].legend()
    fig.suptitle("왜 익일 시가청산인가 — 종가까지 들면 수익이 사라진다")
    fig.tight_layout()
    fig.savefig(path, dpi=150)
    plt.close(fig)

def fig_calibration(df: pd.DataFrame, path: Path) -> None:

    from surge_d1 import models, validate

    folds = validate.walk_forward_folds(df["date"], models.TEST_YEARS)
    tr_mask, te_mask = folds[-1]
    tr = df[tr_mask].reset_index(drop=True)

                              ("prob_cal", "보정 후", "#4C78A8")):
        pt, pp = calibration_curve(te["y_cls"], out[key], n_bins=10,
                                   strategy="quantile")
        ax.plot(pp, pt, "o-", label=label, color=color)
    ax.set_xlabel("예측 확률")
    ax.set_ylabel("실제 상승 빈도")
```

```python
# -*- coding: utf-8 -*-
"""오늘 52주 신고가를 돌파한 종목의 익일 상승확률·기대수익률을 산출한다.

학습은 저장된 데이터셋 전체로 하고, 예측은 최신 봉 후보에 대해 한다.
익일 데이터가 없으므로 라벨 없이 피처만 계산한다.

사용:
    python predict.py                  # 캐시 최신일 기준
    python predict.py --asof 20260828  # 특정일 기준
"""
from __future__ import annotations

import argparse
import sys

import numpy as np
import pandas as pd

from surge_d1 import (config, dataset, features_f1, features_f2,
                      features_f3, models, sources)


def _is_breakout_last(df: pd.DataFrame, i: int) -> bool:
    """익일 존재 조건을 뺀 돌파 판정 (예측 전용)."""
    if i < config.MIN_BAR_INDEX or i >= len(df):
        return False
    c = float(df["Close"].iloc[i])
    v = float(df["Volume"].iloc[i])
    if not np.isfinite(c) or not np.isfinite(v) or c <= 0:
        return False
    if not (c > float(df["Close"].iloc[i - config.HIGH_52W_PERIOD:i].max())):
        return False
    vol_avg = float(df["Volume"].iloc[i - 50:i].mean())
    if not (vol_avg > 0 and v >= config.VOLUME_SURGE_MULT * vol_avg):
        return False
    return bool(c * v >= config.MIN_TRADING_VALUE)


def find_today_events(ohlcv: dict, market: pd.DataFrame,
                      asof: pd.Timestamp) -> pd.DataFrame:
    """asof 날짜에 돌파한 종목과 그 피처(M3)를 모은다."""
    rows = []
    for code, df in ohlcv.items():
        if asof not in df.index:
            continue
        i = int(df.index.get_loc(asof))
        if not _is_breakout_last(df, i):
            continue
        feat = {}
        feat.update(features_f1.compute_f1(df, i, market))
        feat.update(features_f2.compute_f2(df, i, market))
        feat.update(features_f3.compute_f3(df, i))
        rows.append({"code": code, "date": asof,
                     "close": float(df["Close"].iloc[i]), **feat})
    return pd.DataFrame(rows)


def main() -> int:
    sys.stdout.reconfigure(encoding="utf-8")
    ap = argparse.ArgumentParser()
    ap.add_argument("--asof", default=None, help="YYYYMMDD (기본: 캐시 최신일)")
    args = ap.parse_args()

    ohlcv = sources.load_ohlcv()
    market = sources.build_market_index(ohlcv)
    asof = (pd.Timestamp(args.asof) if args.asof
            else max(df.index[-1] for df in ohlcv.values()))
    print(f"기준일: {asof.date()}")

    cand = find_today_events(ohlcv, market, asof)
    if cand.empty:
        print("해당일 돌파 종목 없음")
        return 0
    print(f"돌파 종목 {len(cand)}개")

    train = pd.read_parquet(config.DATASET_PATH)
    train = train[train["date"] < asof]
    feats = dataset.FEATURE_SETS["M4"]
    out = models.fit_predict(train, cand, feats)

    cand["상승확률"] = out["prob_cal"]
    cand["기대수익률"] = out["pred_reg"]
    res = (cand[["code", "date", "close", "상승확률", "기대수익률"]]
           .sort_values("상승확률", ascending=False).reset_index(drop=True))
    res["상승확률"] = (res["상승확률"] * 100).round(1)
    res["기대수익률"] = (res["기대수익률"] * 100).round(3)

    config.RESULTS_DIR.mkdir(parents=True, exist_ok=True)
    path = config.RESULTS_DIR / f"predict_{asof.strftime('%Y%m%d')}.csv"
    res.to_csv(path, index=False, encoding="utf-8-sig")
    print(res.head(20).to_string(index=False))
    print(f"\n저장: {path}")
    print("주의: 이 수치는 연구용 추정치이며 투자 권유가 아니다.")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

### Task 15: 하이퍼파라미터·전처리 민감도 (`tuning.py`)

**Files:**
- Create: `surge_d1/tuning.py`
- Create: `tests/test_tuning.py`

**왜 필요한가 (이 Task의 존재 이유):**

현재 결론은 "ML이 단일 지표(`close_strength`) 대비 7%밖에 못 더한다"이다. 그런데 이 결론은
**물려받은 하이퍼파라미터와 전처리 없음** 위에서 나온 것이라, 발표에서 *"모델을 제대로 안
맞춰서 그런 것 아닌가"* 라는 질문에 답할 수 없다.

물려받은 설정은 실제로 잘못돼 있다:

| | `REG_PARAMS` | `CLF_PARAMS` |
|---|---|---|
| `max_depth` | 3 | **5** |
| `learning_rate` | 0.01 | **0.05** |
| `reg_alpha`/`reg_lambda` | 1.0 / 5.0 | **없음** |

분류기는 정규화가 전무해 학습 AUC 0.77~0.82로 외우고(검정과 격차 +0.20), 회귀는 과정규화로
소표본에서 상수 붕괴한다. 20일 지평·셔플 CV로 튜닝된 값을 검토 없이 이식한 결과다.

전처리도 없다. LightGBM은 트리라 스케일링이 불필요하지만, **횡단면 정규화는 다른 문제다** —
예측 과제가 "그날 돌파 종목들 중 순위"인데 피처가 절대값으로 들어가면 모델이 시장 국면마다
기준을 새로 배워야 한다. 평가 지표(IC)가 일별 순위상관이므로 날짜별 정규화가 목적함수와
정렬된다. qlib도 기본으로 `CSZScoreNorm`을 쓴다.

**핵심 원칙 — 튜닝은 학습 폴드 안에서만 한다.** 검정 결과를 보고 고르면 체리피킹이지만,
학습 구간 내부 검증으로 고르는 것은 표준 관행이며 누수가 아니다. 이 구분을 코드와 리포트에
명시하라.

**Interfaces:**
- Consumes: `config`, `dataset`, `validate`, `models`
- Produces:
  - `cross_sectional_normalize(df, feats, method="rank") -> pd.DataFrame` — 날짜별 정규화
  - `inner_tune(train_df, feats, param_grid, n_splits=3) -> dict` — 학습 폴드 내부 시계열 분할로 최적 파라미터 선택
  - `PARAM_GRID: dict` — 작은 그리드 (아래 근거 참조)
  - `run_sensitivity(df) -> pd.DataFrame` — 조건 A/B/C × 폴드 결과
  - `main()` — `outputs/tuning_sensitivity.csv` 저장

**세 가지 조건:**

| 조건 | 파라미터 | 전처리 |
|---|---|---|
| **A** 물려받음 | `models.REG_PARAMS`/`CLF_PARAMS` 그대로 | 없음 |
| **B** 내부 튜닝 | 폴드별 `inner_tune` 결과 | 없음 |
| **C** 튜닝+정규화 | 폴드별 `inner_tune` 결과 | 날짜별 횡단면 정규화 |

각 조건에서 **M4 피처셋**으로 walk-forward 4폴드를 돌리고, 매 폴드마다 **`close_strength`
단독 정렬**을 같은 방식으로 평가해 상대 우위를 계산한다. 이것이 이 Task의 산출물이다.

```python
# -*- coding: utf-8 -*-
import numpy as np
import pandas as pd
import pytest

from surge_d1 import tuning


def toy(n_days=6, per_day=10, seed=0):
    rng = np.random.default_rng(seed)
    rows = []
    for d in range(n_days):
        date = pd.Timestamp("2024-01-01") + pd.Timedelta(days=d)
        # 날짜마다 스케일이 다르게 만들어 횡단면 정규화의 효과가 드러나게 한다
        base = 100.0 * (d + 1)
        for j in range(per_day):
            rows.append({"date": date, "f1": base + rng.normal(),
                         "f2": rng.normal(), "y_raw": rng.normal() * 0.01,
                         "weight": 1.0 / per_day})
    df = pd.DataFrame(rows)
    df["y_cls"] = (df["y_raw"] > 0).astype(int)
    return df


def test_횡단면정규화는_날짜마다_평균0_분산1로_만든다():
    df = toy()
    out = tuning.cross_sectional_normalize(df, ["f1", "f2"], method="zscore")
    for _, g in out.groupby("date"):
        assert abs(g["f1"].mean()) < 1e-9
        assert abs(g["f1"].std(ddof=0) - 1.0) < 1e-6


def test_횡단면정규화가_날짜간_스케일차이를_제거한다():
    df = toy()
    # 원본은 날짜별 평균이 100,200,...으로 크게 다르다
    raw_spread = df.groupby("date")["f1"].mean().std()
    out = tuning.cross_sectional_normalize(df, ["f1"], method="zscore")
    norm_spread = out.groupby("date")["f1"].mean().std()
    assert raw_spread > 50
    assert norm_spread < 1e-9


def test_rank정규화는_0과1_사이다():
    df = toy()
    out = tuning.cross_sectional_normalize(df, ["f1"], method="rank")
    assert out["f1"].min() >= 0.0
    assert out["f1"].max() <= 1.0
    for _, g in out.groupby("date"):
        assert g["f1"].nunique() == len(g)      # 순위이므로 동점이 없어야 한다


def test_정규화는_라벨을_건드리지_않는다():
    df = toy()
    out = tuning.cross_sectional_normalize(df, ["f1", "f2"], method="zscore")
    pd.testing.assert_series_equal(out["y_raw"], df["y_raw"])
    pd.testing.assert_series_equal(out["y_cls"], df["y_cls"])


def test_inner_tune은_검정데이터를_보지_않는다(monkeypatch):
    """전달된 학습 프레임 밖의 행이 결과에 영향을 주면 안 된다."""
    df = toy(n_days=12, per_day=12)
    train = df[df["date"] < pd.Timestamp("2024-01-09")]
    grid = {"max_depth": [2, 3], "learning_rate": [0.05]}
    best_a = tuning.inner_tune(train, ["f1", "f2"], grid, n_splits=2)
    # 학습 프레임은 그대로 두고 그 뒤 구간만 값을 오염시킨다
    poisoned = df.copy()
    mask = poisoned["date"] >= pd.Timestamp("2024-01-09")
    poisoned.loc[mask, ["f1", "f2", "y_raw", "y_cls"]] = 999.0
    train_p = poisoned[poisoned["date"] < pd.Timestamp("2024-01-09")]
    best_b = tuning.inner_tune(train_p, ["f1", "f2"], grid, n_splits=2)
    assert best_a == best_b


def test_inner_tune의_내부분할도_시간순이다():
    """내부 검증 분할이 무작위면 시계열 튜닝의 의미가 없다."""
    df = toy(n_days=12, per_day=8)
    splits = tuning.inner_time_splits(df["date"], n_splits=3)
    assert len(splits) == 3
    d = pd.to_datetime(df["date"])
    for tr, va in splits:
        assert d[tr].max() < d[va].min()


def test_inner_tune은_그리드안의_값을_돌려준다():
    df = toy(n_days=12, per_day=12)
    grid = {"max_depth": [2, 4], "learning_rate": [0.05, 0.1]}
    best = tuning.inner_tune(df, ["f1", "f2"], grid, n_splits=2)
    assert best["max_depth"] in grid["max_depth"]
    assert best["learning_rate"] in grid["learning_rate"]
```

`surge_d1/tuning.py` 를 작성한다. 요구사항:

**`inner_time_splits(dates, n_splits)`** — 학습 프레임 **안에서** 시간순 확장 분할을 만든다.
무작위 K-fold를 쓰면 이 연구가 비판하는 바로 그 오류를 튜닝 단계에서 반복하는 셈이다.

**`inner_tune(train_df, feats, grid, n_splits=3)`** — 내부 분할의 평균 AUC를 기준으로 그리드
최적점을 고른다. **`train_df` 밖의 어떤 행도 읽지 않는다.** 분류기 파라미터를 튜닝하고,
회귀는 같은 `max_depth`/`learning_rate`를 공유하되 정규화 항은 그리드에 포함한다.

**`PARAM_GRID`** — 작게 유지한다. 그리드가 크면 튜닝 자체가 과적합한다. 다음을 근거로 삼아라:
현재 분류기는 정규화가 없고(`reg_alpha`/`reg_lambda` 미지정) `max_depth=5`라 학습 AUC가
0.82까지 오른다. 따라서 그리드는 **깊이를 줄이는 방향**과 **정규화를 넣는 방향**을 반드시
포함해야 한다. 예: `max_depth ∈ {3, 5}`, `learning_rate ∈ {0.02, 0.05}`,
`reg_lambda ∈ {0, 5, 20}`, `min_child_samples ∈ {20, 100}`. 조합 수를 24 이하로 유지하고,
왜 이 범위인지 주석으로 남겨라.

**`cross_sectional_normalize(df, feats, method)`** — 날짜별로 정규화한다.
`method="rank"` 는 `[0,1]` 백분위, `"zscore"` 는 평균 0 분산 1. **라벨·가중치·식별자 컬럼은
절대 건드리지 않는다.** 하루에 종목이 1개뿐이면 z-score가 0/0이 되므로 그 경우의 처리를
정하고 주석으로 남겨라. NaN 피처는 NaN으로 유지한다(LightGBM이 분기로 학습한다).

**`run_sensitivity(df)`** — 조건 A/B/C × 4폴드를 돌린다. 각 폴드에서:
1. `models.assert_train_before_test` 로 시간순을 확인한다
2. 조건 B/C는 **그 폴드의 학습 구간만으로** `inner_tune` 을 호출한다
3. 조건 C는 정규화를 **학습·검정 각각의 날짜 안에서** 수행한다 — 전체 기간 통계를 쓰면
   미래정보 누수다. 날짜별 정규화는 그날 안에서만 계산되므로 본질적으로 안전하지만,
   구현이 실제로 그런지 테스트로 확인하라
4. 같은 폴드에서 `close_strength` 단독 정렬을 평가해 상대 우위를 계산한다

`n_jobs=1`로 고정해 재현 가능하게 한다.
