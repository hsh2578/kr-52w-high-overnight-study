# 검증 스크립트

질문 하나에 답하려고 한 번 돌린 스크립트입니다. 결과는 `outputs/`에 CSV로 떨어집니다.
저장소 루트에서 `python -m studies.<이름>` 으로 실행합니다.

| 스크립트 | 질문 | 답 |
|---|---|---|
| `model_compare.py` | 어떤 모델 계열이 이 문제에 맞나 | 10종의 AUC가 0.517 ~ 0.554에 몰림. 모델 차이보다 선별 행위 자체의 효과가 큼 |
| `feature_study.py` | 피처 50개 중 실제로 신호가 있는 것은 | \|t\| ≥ 2 인 것은 11개. 변수를 줄이거나 PCA를 걸면 오히려 나빠짐 |
| `ai_vs_plain.py` | 스크리너의 AI 점수가 그냥 돌파보다 나은가 | 20일 내 최고 수익은 높지만 20일 뒤 실제 수익은 차이 없음 (p=0.84) |
| `active_exit.py` | 목표가에 닿으면 파는 규칙이면 살아나나 | 살아나지 않음 |
| `trend_exit.py` | 추세추종 청산 4종이면 살아나나 | 네 규칙 모두 AI 우위가 유의하지 않음 |

`ai_vs_plain.py`, `active_exit.py`, `trend_exit.py`는 다른 프로젝트(주식 스크리너)의 학습
자료를 읽습니다. 그 자료는 이 저장소에 없습니다.
